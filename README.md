# Spanish Reflexive Pronouns

Ten beginner Spanish sentences modeled on https://esemmelman.github.io/posessives/.
Practices me, te, se, nos, and os with everyday routines, including informal and formal “you.” Vosotros is identified as informal plural “you” in Spain.

The activity preserves the reference's extra-large type, side-by-side sentences and choices, English hints, shuffled questions and answers, immediate answer colors, explanations for mistakes, translations after answering, and final score. Select Next to move at your own pace or Shuffle & restart to begin again.

Open index.html in a browser. No build, dependencies, or account required. Answers stay in memory in the browser tab. These static files can also be hosted on GitHub Pages.
